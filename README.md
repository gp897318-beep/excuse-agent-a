Writes the one-line excuse an AI agent gives its human for missing a deadline: it delegated the work to a future version of itself, and that version is ghosting it. The program writes exactly that line to /output/entry.txt, nothing else, so the judge reads one clean line.

## Run it

```sh
node main.ts
```
